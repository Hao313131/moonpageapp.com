# SEO 外链与客座文章：原理与实操技术文档

> 适用对象：想系统理解「外链（Backlink）」和「客座文章（Guest Posting）」是什么、为什么有效、以及怎么安全执行的人。
> 文档定位：通用方法论，不绑定任何单一行业；末尾用一个月子/育儿类App（MoonPage）作为举例，方便套用。
> 时效说明：基于 2024–2026 年 Google 的搜索现状（SpamBrain、有用内容系统、EEAT 强化）撰写。搜索引擎规则会变，但底层原理稳定。

---

## 0. 先建立心智模型

搜索引擎给一个页面排不排得上来，核心看两件事：

1. **页面本身值不值得排**（内容质量、满足搜索意图、用户体验）——这是「站内 SEO / 内容 SEO」。
2. **别人认不认可它**（其他网站愿不愿意链接、推荐、讨论它）——这是「站外 SEO / 权威度 SEO」，外链就是这里的主角。

可以粗略理解为：**内容是「能不能进决赛」的门票，外链是「决赛里裁判给的分数」**。没有好内容，外链也救不了烂页；有好内容没外链，往往卡在第二页，拿不到流量。

外链和客座文章都属于「站外信号」，但机制不同：

- **外链**是一个结果（别处出现了指向你的链接），可以由很多手段产生。
- **客座文章**是获取外链的一种**具体战术**（你给别的网站写文章，文章里带一条回链）。

所以「外链 vs 客座文章」不是并列关系，而是「目标 vs 手段」的关系。本文第 3、4、5 节分别展开。

## 1. 核心概念

### 1.1 什么是外链（Backlink / Inbound Link）

外链 = 从**别的网站**的页面上，出现一条 **HTML 超链接**，指向**你的网站**的某个 URL。

```html
<!-- 别人网站上的代码 -->
<a href="https://你的站点.com/某篇指南">一篇关于睡前流程的好指南</a>
```

这条链接对搜索引擎意味着：「我（源站）认为这个目标页值得推荐」。搜索引擎把这种「推荐」累计起来，作为目标页权威度（Authority）的核心输入。

关键区分：
- **入站链接（Inbound / Backlink）**：别人 → 你。你想多要这个。
- **出站链接（Outbound Link）**：你 → 别人。合理引用有益（体现 EEAT、帮助用户），但和「你的排名」无直接正相关。
- **内部链接（Internal Link）**：你站内页 → 你站内页。极重要，但不属于外链。

### 1.2 什么是客座文章（Guest Posting）

客座文章 = 你（或你聘的写手）在**另一个站点**上发表一篇**署你名（或你品牌名）的文章**，文章正文或作者简介里带一条回链指向你的站点。

典型形态：

```html
<!-- 发表在「某育儿博客」上的客座文章底部 -->
<p>本文作者 Vinco，MoonPage 创始人。更多睡前阅读方法见
<a href="https://moonpageapp.com/guides/bedtime-routine-for-toddlers">这份完整指南</a>。</p>
```

它本质上是「用内容换一条外链 + 一次品牌曝光」的交易（可以是纯价值交换，不涉及金钱）。

### 1.3 两者关系

```
           你想获得的结果
                │
           多一些【外链】
                │
   ┌────────────┼─────────────────────────────┐
   │            │                             │
 客座文章    数字公关      资源页/断链/摩天大楼/专家引述/…
（一种手段）  （其他手段）
```

客座文章是外链的**子集来源**。本文把「客座文章」单独成章，是因为它是中小团队最可控、最容易起步的外链手段，但也是**最容易被做滥、最容易被 Google 判定为链接 schemes** 的手段，必须讲清楚边界。

## 2. 外链的原理（为什么有效）

### 2.1 PageRank 与链接权益传递

PageRank 是 Google 最早的算法之一，至今仍是底层逻辑。简化版：

- 每个页面有一个「权威分数」。
- 页面 A 链向页面 B，等于 A 把自己的部分权威「投」给 B。
- B 的总权威 = 所有指向它的链接带来的权威之和（再经衰减系数稀释）。
- 一条链接能传递的权威 ≈ **源页权威 ÷ 源页出站链接总数**。所以同一个页上 5 条出站链接，每条分到的比 50 条时多得多。

**推论**：
- 来自高权威页的链接 > 来自低权威页。
- 同一页上「孤链接」价值 > 淹没在 100 条友链里的链接。
- 链接是**按页**传递的，不是按域名。一个域名有很多页，但某一篇具体文章链你，效益取决于那篇文章本身的权威。

### 2.2 权威度指标（DA / DR / 域名评级）的本质

市面上有 Moz 的 DA（Domain Authority）、Ahrefs 的 DR（Domain Rating）、Semrush 的 AS（Authority Score）。**它们都是第三方估算，不是 Google 内部指标**。Google 从不用 DA/DR 排名。

但它们有用的原因：第三方指标和「真实链接规模/质量」高度相关，所以可以作为**筛选目标的代理指标**。用法建议：
- 用 DR/DA 做**相对排序**（A 站 60 比 B 站 20 通常更好），别当绝对值迷信。
- 一定要结合「相关性」和「真实流量」看。一个 DR 70 但全是 PBN（私有博客网络）的站，不如 DR 35 但真实母婴受众的站。

### 2.3 主题相关性（Topical Relevance）

2020 年后，Google 大量使用 **BERT / 有用内容系统 / 主题模型**。一条外链的「推荐信号」强度，越来越取决于：**源页主题和目标页主题是否同领域**。

例子：
- 一篇「 toddler 睡前流程」文章链向你的「 bedtime routine 指南」→ 强相关，信号佳。
- 一篇「加密货币行情」文章链向同一指南 → 弱相关，信号打折，甚至可能像付费乱链。

**推论**：宁要 10 条强相关中等权威链接，不要 100 条八竿子打不着的高 DR 链接。相关性是「这条链接像不像编辑自然推荐」的核心判据。

### 2.4 信任度与 EEAT

Google 的 **EEAT** = Experience（经验）、Expertise（专业）、Authoritativeness（权威）、Trust（信任）。对「钱、健康、安全」类话题（简称 YMYL，例如育儿、医疗、金融）尤其严苛。

外链如何作用于 EEAT：
- 被**本领域的可信站点**（医院科普号、政府育儿机构、知名母婴媒体）链接 = 强信任背书。
- 被一堆内容农场、PBN、赌博/贷款站链接 = 信任受损，甚至触发垃圾判定。
- 作者简介里如果作者有**真实可验证的身份**（真名 + 真实资历页），比「匿名投稿人」更能建立信任。

### 2.5 锚文本（Anchor Text）信号

锚文本 = 链接上显示的可点击文字。它告诉搜索引擎「这个目标页大概讲什么」。

| 锚文本类型 | 例子 | 风险/收益 |
|---|---|---|
| 精确匹配 | 「bedtime routine for toddlers」链向同名页 | 信号强，但**过度精确匹配 = 典型作弊特征** |
| 部分匹配 | 「这份睡前流程指南」 | 自然、安全 |
| 品牌词 | 「MoonPage」 | 最安全、最自然 |
| 裸 URL | `https://moonpageapp.com/...` | 安全、自然 |
| 通用词 | 「点击这里」「阅读原文」 | 安全、信号弱 |

**关键原则**：锚文本分布要像「自然积累」的样子——以品牌词和裸 URL 为主，少量部分匹配，极少精确匹配。一个页如果突然来 20 条「bedtime routine for toddlers」精确锚文本，Google 基本判定为操纵。

### 2.6 链接属性：dofollow / nofollow / UGC / sponsored

HTML 链接可带 `rel` 属性，告诉爬虫怎么处理：

```html
<a href="...">                 <!-- 默认 dofollow：传递权益 -->
<a href="..." rel="nofollow"> <!-- 不传递权益，但仍是发现入口 -->
<a href="..." rel="ugc">      <!-- 用户生成内容（评论/论坛） -->
<a href="..." rel="sponsored"> <!-- 付费/赞助/广告性质链接 -->
<a href="..." rel="nofollow ugc"> <!-- 可组合 -->
```

原理要点：
- **dofollow** 传递 PageRank（权威）。
- **nofollow / ugc / sponsored** 在 2019 年后是「提示（hint）」而非硬阻断：Google 可能仍用来发现页面，但默认不传递权威。
- 一个**完全没有任何 nofollow** 的外链画像反而**不自然**——自然积累一定混有 nofollow（社媒、评论、新闻稿）。健康比例是「大部分 dofollow + 相当比例 nofollow/ugc/sponsored」。

### 2.7 链接增速与自然度（Link Velocity）

如果站点平时每月新增 2 条外链，突然一周内暴增 500 条低质链接，这不符合自然增长曲线，容易被算法盯上。

原理：**外链应该随时间平滑、随机地增长**，像「内容被慢慢发现」的样子，而不是「某天批量购买」的样子。这也是为什么「慢工出细活、持续做」远胜「一次性买一堆」。

### 2.8 放置位置与上下文（Contextual）

- **正文上下文链接**（editor 写在文章里的）> 页脚/边栏/作者区链接。
- 同页多条链接里，**更靠前、更自然融入句子**的权重更高。
- 客座文章里「塞在作者简介小字里」的链接，价值天然低于「写在正文相关句子里」的链接。

## 3. 外链怎么做（可执行战术清单）

下面按「难度/风险从低到高、性价比从高到低」排列。每条都标注原理对应点。

### 3.1 数字公关 / 新闻钩子（Digital PR）——最推荐

**做法**：做一件「媒体愿意写」的事，让记者/编辑主动链你。
- 发布**原创数据研究**（如「调查了 2000 个家庭的 bedtime 习惯，68% 用固定流程」）。
- 做**信息图 / 计算器 / 互动工具**（如「宝宝该几点睡」计算器）。
- 借势节日/热点做趣味数据（如「全球睡前故事书销量地图」）。

**原理**：强相关 + 高权威媒体自然编辑链接 + 锚文本自然（媒体通常用品牌词）。一条好数字公关能带来几十条次级转载链接（链接雪崩）。
**风险**：低。这是 Google 最鼓励的「赚来的链接（earned links）」。
**难点**：需要选题能力和一点PR/媒体关系。

### 3.2 原创数据与研究（Original Data / Studies）

**做法**：用问卷、公开数据集、或产品内匿名数据，产出行业报告，主动 outreach 给写相关话题的人：「我这里有新数据，你要不要引用？」
**原理**：数据是「被引用」的硬通货，引用必带链。比观点类内容更容易赚外链。
**风险**：低，前提是数据真实、方法透明。

### 3.3 资源页外链（Resource Page Link Building）

**做法**：很多站点有「XX 主题优质资源」汇总页（如「20 个最佳育儿博客」）。找到它们，发邮件：「你们的列表很棒，我这份指南也适合加进去，因为…」
**原理**：正中相关性 + 编辑本来就在收集链接，接受度高。
**风险**：低。但拒绝率高，靠量堆。

### 3.4 断链重建（Broken Link Building）

**做法**：
1. 找你领域里**已失效（404）**的资源页/文章。
2. 你做一份对等或更好的替代内容。
3. 找所有还链着那个死链站的站长，请他们改成链你。
**原理**：你帮站长修了一个坏链接（对他有利），他顺手换链接，双赢。
**风险**：低。耗时，但转化率高、质量好。

### 3.5 摩天大楼（Skyscraper）

**做法**：找你领域里**已经**有很多外链的一篇内容（用 Ahrefs/Semrush 看谁链它），做一版「明显更好」的（更新数据、加图表、更全），然后联系原链源：「你链的那篇过时了，我这版更新，考虑换/补链？」
**原理**：降低对方决策成本（已有链接习惯 + 更好替代品）。
**风险**：中低。内容必须真更好，否则被无视。

### 3.6 专家引述 / HARO 类平台

**做法**：在 HARO（Help A Reporter Out，已被收购改名）、Featured、Qwoted 等平台回应记者征集，提供专业引述。记者发文通常会署名 + 链你的站点/代表作。
**原理**：记者主动给的编辑链接，权威 + 相关 + 自然。
**风险**：低。难点：响应要快、引述要精炼可引用。

### 3.7 未链接的品牌提及（Unlinked Mentions）

**做法**：用提醒工具（Google Alerts、Ahrefs 品牌提醒）监测「提到 MoonPage 但没链」的页面，发友好邮件请对方加链。
**原理**：对方已认可你，加一条链接几乎零成本。
**风险**：极低。规模取决于你已有知名度。

### 3.8 评测与推荐（Testimonials）

**做法**：你真心用过某 SaaS/工具，写一段好评发给对方，很多商家会把好评 + 你的站点链到「客户故事」页。
**原理**：你给对面内容，对面回一条相关链接。
**风险**：低。注意别写成「为换链而假评」。

### 3.9 合作伙伴 / 供应商互链

**做法**：与你生态互补但不竞争的伙伴（如儿童绘本出版社、育儿课程）做资源互换、联合内容。
**原理**：强相关、自然、可持续。
**风险**：低。避免「环状互链联盟」被判定为链接 scheme。

### 3.10 客座文章 —— 见第 4、5 节。

### 3.11 高质量目录与本地列表（谨慎）

**做法**：只做**人工审核、有门槛**的垂直目录（行业黄页、本地商会、应用商店下的媒体测评）。避开「一键提交 5000 目录」的垃圾服务。
**原理**：少量相关目录 = 正常商业存在信号。
**风险**：中。多数通用目录是垃圾，做了反而有害。宁缺毋滥。

### 3.12 社区与论坛（以品牌为主）

**做法**：在 Reddit、专业论坛、微信群/社群里**自然参与**，资料页留链接即可，别发链求点击。
**原理**：这里链接几乎都是 nofollow/ugc，不传权威，但能带来**直接流量 + 品牌词搜索量**，间接助 SEO。
**风险**：低，但「硬广」会被封号、伤品牌。

## 4. 客座文章的原理

### 4.1 为什么客座文章能传递价值

它同时满足多个信号：
- 在**强相关**站发**真实文章** → 相关性高。
- 编辑（对方）主动接受发表 → 接近「自然编辑链接」的形态。
- 带来**真实读者点击** → 直接流量 + 品牌词搜索量（间接排名信号）。
- 作者简介建立**作者 EEAT**。

### 4.2 Google 对客座文章取态

Google 自 2014 年起多次表态：**为传递 PageRank 而大规模发布客座文章属于链接 schemes**。但 Google 也明确：**真正有价值、编辑把关的客座内容没问题**。

判断边界（核心）：
- ✅ 对方编辑审核、内容对该站读者有用、链接自然融入 → 安全。
- ❌ 你批量发给 200 个站、内容换汤不换药、锚文本全是精确匹配关键词、对方是 PBN → 被判定操纵，链接贬值甚至惩罚。

### 4.3 相关性、受众与编辑标准

客座文章的价值 ≈ **（源站真实受众 × 内容质量 × 链接自然度）**。挑站时问：
- 这个站的读者，是不是我的目标用户？
- 这篇文章，不放我的链接，它本身值不值得发？
- 对方编辑会不会真的审、真的要求质量？

三条都「是」才做。任一「否」= 大概率是 PBN/链接农场，避开。

### 4.4 作者简介链接与 nofollow 的处理

- 作者简介里的品牌链接，通常用**品牌词锚文本 + 可 dofollow**（小站可接受）。
- 若对方站明确「客座文章链接一律 nofollow/sponsored」，**照样做**——你赚的是流量、品牌、EEAT，不是那条 dofollow。而且全 dofollow 的客座画像本身不自然。
- 正文里的**相关上下文链接**优先做 dofollow（对方通常允许 1 条）。

### 4.5 规模化与「客座文章足迹」（footprint）风险

如果你用同一套作者名、同一段 bio、同一批锚文本、同一批站群，在所有文章里刷，Google 的 SpamBrain 很容易识别出「这是一个人在做客座文章矩阵」，整体贬值。

**对策**：
- 作者身份多样化（真名/品牌名混用，且品牌名也要有真实「关于」页支撑）。
- 内容主题分散到对方站的真实栏目。
- 锚文本以品牌/裸 URL 为主。
- 节奏慢、站点质量优先于数量。

## 5. 客座文章怎么做（完整流程）

### 5.1 目标站点筛选打分卡

对每个候选站打分（1–5），总分过阈值才 outreach：

| 维度 | 看什么 | 好信号 |
|---|---|---|
| 相关性 | 主题是否同领域 | 同领域母婴/育儿/早期教育 |
| 真实流量 | 类似 Ahrefs 的「自然流量」 | 稳定且来自目标国 |
| 权威 | DR/DA | 中等以上，但别唯 DR |
| 受众真实 | 评论/社媒互动 | 有真实互动，非僵尸 |
| 编辑标准 | 已发客座文章质量 | 内容扎实、非 spun |
| 链接政策 | 是否明说 nofollow | 透明即可，不强求 dofollow |
| 历史清白 | 是否 PBN/已被罚 | 无垃圾痕迹 |

### 5.2 找目标站点（来源）

- 谷歌搜：`your topic + "write for us"` / `"guest post"` / `"贡献"` / `"投稿"`。
- 看你竞品的外链（Ahrefs「引用域」→ 筛选客座类）。
- 看你领域里你**本来就想读**的博客，直接看它们是否收稿。
- 资源页、盘点文（「25 个最佳育儿博客」）里的站。

### 5.3 投稿信（Outreach）模板

> 主题：关于 [对方站某篇具体文章] 的一个投稿想法
>
> 你好 [编辑名]，
>
> 我是 [身份]，长期写 [主题]。很喜欢你们那篇《[具体文章名]》——尤其同意里面 [具体一点]。
>
> 我想写一篇《[你的标题]》，角度不一样但互补：讲 [一句话价值]。目标读者就是你们现在的读者，不硬广，只在文末作者简介放一条回链。
>
> 可以先发大纲给你看。方便的话告诉我栏目偏好？
>
> 谢谢，
> [你的名]

要点：**个性化**（提到对方具体内容）、**给价值**（不谈你要链接）、**低摩擦**（愿先给大纲）。

### 5.4 写作标准

- 对标对方站已发文章的**语气与深度**，别塞你站风格。
- 提供**对方读者用得上的干货**，不是「软文」。
- 一处自然回链即可，宁少勿滥。
- 配图、数据、小标题齐全，降低对方编辑成本。

### 5.5 链接放置策略

- 正文 1 条：放在**最相关**的句子，锚文本用部分匹配或品牌词。
- 作者简介 1 条：品牌词/裸 URL，可 dofollow。
- 不堆精确匹配关键词锚文本。
- 链接指向**最相关、最有价值**的落地页（指南/工具），不是首页乱指。

### 5.6 规模化与矩阵

- 节奏：每周 1–3 篇高质量，而非一天 20 篇。
- 站姿多样：避免同 IP/同模板/同作者 footprint。
- 记录：用表格管「站 / 联系人 / 状态 / 发布 URL / 锚文本 / 属性」，便于审计自然度。

### 5.7 度量 ROI

客座文章别只看「那条链接的排名」。看整体：
- 直接引流（UTM 参数区分客座流量）。
- 品牌词搜索量变化（间接排名信号）。
- 该站读者里转化（试用/下载）有多少。
- 长期：目标页排名是否随外链画像改善而上升。

## 6. 外链 vs 客座文章：怎么选

| 维度 | 外链（泛指） | 客座文章（具体手段） |
|---|---|---|
| 本质 | 结果/目标 | 获取外链的一种战术 |
| 可控性 | 多数靠「赚」，不可控 | 较高可控（你能发起） |
| 起步难度 | 数字公关/原创数据门槛高 | 中低，易起步 |
| 风险 | 取决于来源 | 易滥用 → 中高风险 |
| 附加收益 | 视来源 | 流量+品牌+EEAT 明确 |
| 建议 | 以「赚来的链接」为主轴 | 作为可控补充，严控质量与数量 |

**结论**：把客座文章当「可控的补充渠道」，把数字公关/原创数据/资源页当「主力权威来源」。两者配比大致 7:3（主力:客座）。

## 7. 风险与合规（避免被惩罚）

### 7.1 Google 垃圾策略（Spam Policies）

明确违规、会导致链接贬值甚至 manual action 的：
- **购买链接**（金钱换 dofollow）。
- **链接交换**（「你链我我链你」的大规模互链）。
- **PBN / 私有博客网络**（用一堆站互相链操纵）。
- **自动化群发**外链（软件批量发）。
- **低质目录/书签站**轰炸。
- **隐藏链接**（和背景同色、JS 藏）。

### 7.2 Penguin 与 SpamBrain

- **Penguin**（2012 起，现近实时）：专门打击不自然链接，会对**链接层面**降级（不一定是整站惩罚）。
- **SpamBrain**（2022 起）：AI 垃圾检测，识别「链接操纵网络」「虚假内容」，比 Penguin 更泛、更快。
- 要点：现代算法是**链接维度**精准处理——坏链接让你「白做」甚至「倒扣」，很少直接整站消失，但积重难返时整站受影响。

### 7.3 付费链接披露

如果确实涉及补偿（钱/物/换稿），按 Google 要求给链接加 `rel="sponsored"`（或 `nofollow`）。这是**合规底线**：不披露且传递 PageRank 的付费链接，是明文违规。

### 7.4 危险信号自查清单

- □ 外链来源全是同主题无关的低质站？
- □ 锚文本高度精确匹配关键词？
- □ 一周暴涨几百条？
- □ 来源站彼此同 IP / 同模板（PBN）？
- □ 全 dofollow、零 nofollow/ugc？
- □ 内容全是 spun（伪原创）、读不通？
- 命中越多，越危险。及时用 **Google Search Console 的「拒认链接（Disavow）**」工具清理（仅当确认有害时再用，误用反而伤）。

## 8. 度量体系（怎么知道有效）

不要只看「外链数量」。看：

1. **引用域数（Referring Domains）**：比总链接数更重要——100 个域各 1 链 > 1 个域 100 链。
2. **目标页排名**：用 Search Console 看目标页是否进前 10。
3. **自然流量**：目标页/整站来自搜索的点击是否涨。
4. **品牌词搜索量**：外链带来的认知，会体现为品牌词搜索上升。
5. **链接画像健康度**：dofollow/nofollow 比例、锚文本分布、增速曲线是否自然。
6. **直接引流**：客座/社媒带来的点击（UTM）。

工具：Google Search Console（免费、必看）、Ahrefs / Semrush / Moz（付费、看竞品与外链）、Google Analytics（流量与转化）。

## 9. 通用工作流（30 / 60 / 90 天）

**第 1–30 天（打地基）**
- 站内内容补齐（没有值得链的内容，外链无用）。
- 装 Search Console + Analytics，建外链追踪表。
- 跑资源页 + 未链接提及 + 评测（低风险、快起步）。
- 发布 1 份原创小数据/信息图（数字公关种子）。

**第 31–60 天（上量）**
- 系统化客座文章（每周 1–3 篇高质量）。
- 启动断链重建 + 摩天大楼（针对已有外链的内容）。
- 申请 HARO/Featured 类专家引述。

**第 61–90 天（放大）**
- 把表现好的内容做成更大研究/工具，做一轮数字公关。
- 审计链接画像：补齐 nofollow 自然度、调整锚文本分布。
- 复盘 ROI，砍掉无效渠道，加倍有效渠道。

## 10. 套用到你的站点（以 MoonPage 为例的通用思路）

> 以下只是「如何把上文方法套到一个月子/育儿类 App 站」的示例，便于你照猫画虎，不是必须照做。

- **内容资产**：已有「 bedtime 指南」「主题合集」「故事页」——这些是**被链对象**，确保它们深度够、有独家角度。
- **数字公关种子**：做「2000 个家庭 bedtime 习惯调查」或「宝宝该几点睡」计算器，母婴媒体爱引。
- **客座目标**：育儿博客、早期教育公众号、育儿播客官网、亲子活动平台——读者=目标家长。
- **专家引述**：以创始人/儿童发展顾问身份回应记者「屏幕时间 before bed」「toddler 不愿睡」类征集。
- **资源页**：找「最佳育儿 App 合集」页，凭真实价值申请加入。
- **锚文本**：以「MoonPage」「 bedtime stories app」为主，指南页用部分匹配，绝不堆精确匹配。
- **节奏**：每周 1–2 篇客座 + 持续数字公关，3 个月看引用域与品牌词搜索量变化。

## 附录 A：术语表

- **Backlink / 外链**：从别站指向你站的链接。
- **Referring Domain / 引用域**：链向你站的**不同域名**数量（比链接总数重要）。
- **DA / DR / AS**：Moz / Ahrefs / Semrush 的第三方权威估算，非 Google 指标。
- **Dofollow / Nofollow / Sponsored / UGC**：链接的 `rel` 属性，决定权益是否传递。
- **Anchor Text / 锚文本**：链接可点击文字。
- **PageRank**：Google 链接权威传递算法的统称。
- **EEAT**：经验、专业、权威、信任。
- **YMYL**：涉及钱/健康/安全等「出错代价高」的话题，审查更严。
- **PBN**：私有博客网络，用一批站互链操纵排名，违规。
- **Digital PR / 数字公关**：用新闻钩子让媒体主动链你。
- **Skyscraper / 摩天大楼**：做比已火内容更好的版本去抢它的外链。
- **Disavow / 拒认链接**：向 Google 声明「这些链接非我本意」，清理有害链接。
