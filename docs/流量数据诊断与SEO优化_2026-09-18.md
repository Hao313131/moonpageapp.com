## 0. 一句话结论

**这批数据不支持"改哪个页面的标题/描述"，它支持的是"把已经跑赢的页面形状复刻到已经排到第 1–2 页的页面上"。**

三条硬事实（**第 1 条已在第三轮被修正，见 §2**）：

1. ~~**`/picture-books-for-kids/` 是全站唯一被证明的"陌生人转化器"**~~ → **修正**：它 90 天 14 次点击 / 101 曝光 / CTR 13.86% / 平均排名 18.5 是**真的**，但**点击来自品牌 sitelink 簇**（该页可见查询里 `site:` 占 18/25，5 条非品牌查询合计 7 曝光 0 点击），**不是自然搜索**。同排名区间的 `/stories/` 2.86%、`/stories/counting-sheep/` 和 `/bedtime-stories/` 0%，仍是有效对照，但**不能拿 sitelink 页去比自然搜索页**。
2. **站内确实有页面已经排在第 1 页**：`/guides/bedtime-stories-for-4-year-olds/` 归一化后平均排名 **10.1**、CTR **12.50%**、3 点击——**这是全站唯一可归因到自然搜索的内容页**；`/cozy-bedtime-stories/` 排名 **8.8**。旧结论"没有任何查询排在 4–20 位"**作废**（见 §2 为什么）。
3. **绝大部分"有曝光没点击"的页面是 `site:` 自查询（sitelink），不是缺陷**；另一大块是别人家书名 + `read online/pdf/epub`（A 段），永远转化不了。**这两类占了总曝光的一半以上，把它们剔掉之后，真正可推的靶心很小、很明确——小到只剩 1–2 个页面。**

**由此推出的期望管理**：站内内容改动的可验证上限很低。90 天全站 121 点击里 54 次（45%）来自 5 个品牌查询，可见的非品牌 198 曝光是 **0 点击**。**继续只做站内，期望值按「个位数点击/月」估。**

**第四轮补充（技术面收口）**：站内已经基本做到头 —— 全站 171 页、**8,166 条内链断言 0 断裂**；`<title>` 0 条超 60；`<meta description>` 0 条超 155；**954 个 JSON-LD 块 0 解析失败、0 个无尾斜杠站点 URL**（改前 794 个）；`CollectionPage` 覆盖 **23 页**（改前 1）。**这意味着下面"还剩什么"的答案基本只剩站外（权重/外链）+ 一个页面加深（§6.2）。**

### 一个独立发现：标题被反复改动

窗口内被改过标题的至少有：首页（4 版）、`/bedtime-stories/`（2 版）、`/faq/`、`/guides/`、`/support/`、以及 45 个故事页的旧模板 `X — Bedtime Story · MoonPage`。

> **标题纪律（2026-09-18 起）：标题冻结。** 除非同时满足 ① ≥4 周稳定观测窗口 ② 一个明确可归因的假设，否则不再改首页与故事页标题。

### ⚠️ 旧结论作废：「没有任何查询排在 4–20 位」

查询×页面交叉表**被 GSC 严重截断**，不能用来做"某排名段没有查询"的否定判断：

**缺口 2：`storyMetaDescription` 的实现和它自己的注释相反（本轮最值钱的一处）**
