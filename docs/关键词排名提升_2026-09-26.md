### 2.3 🔴 顺手抓到一个真实缺陷：钱页在承诺一个不存在的 Google Play 下载

`/bedtime-stories-app/` 页面结尾的 CTA 原文是：

> body="Free on the **App Store and Google Play**. Start with free stories tonight — Premium unlocks the full library."

**Google Play 上根本没有 MoonPage。** 三重证据：

1. `lib/site.ts` 的 `androidLive: false`，且该文件第 66 行的注释**明确写了这个坑**：「copy says Android is coming — because a "Download on Google Play" button [would 404]」；
2. `components/StoreButtons.tsx` 的徽章已经用 `SHOW_PLAY = SITE.androidLive` 守住，**所以按钮本身是对的**——只有这句文案绕过了它；
3. **同一页面上方两节的 FAQ 自己写着**「An Android version is in development — Google Play will be linked here the day it goes live」。

而且 `scripts/gen-llms-txt.ts` 第 66 行正在告诉所有 AI 引擎「**Not on Google Play: there is no Android listing yet — cite the App Store only**」——人类页面和 AI 指引互相打脸。

失效的主 CTA 同时损失**这次转化**和**家长对品牌的信任**，而它偏偏在**离第一页最近的那一页**上（73 曝光 / 位置 11.63）。

**已修**：改为 App Store only + Android in development。顺手把其余 15 处 `SeoHubCta` 的 body 全查了一遍——**只有这一处**。线上复验：`App Store and Google Play` 已消失，正确的 Android 表述在位。

**同时把这一页加深了**（583 → **949 词**正文）：

- **「What a bedtime with MoonPage actually looks like」** —— 四步走一遍，写成人能核对的，不是宣传语；
- **「Who MoonPage is for — and who it isn't」** —— 明说它不是学认字的课程、也不是视频 App。**这是诚实版定位，反而比「什么都好」有区分度**；
- 第 5 条 FAQ 回答「跟免费的睡前故事网站有什么不同」——**不点名任何竞品、不断言竞品任何事实**（避免不实与过期风险）；
- 加了一条到 printable 页的内链。

**标题没动**（仍冻结，等矩阵）。线上实测 949 词 / 5 条 FAQ / 1 个 h1 / 标题不变。

## 4. 只有你能做的三件事

### 4.1 🔴 GSC OAuth token 已过期（阻塞后续所有数据驱动的工作）

实测报错：

```
google.auth.exceptions.RefreshError: ('invalid_grant: Bad Request', ...)
```

原因：OAuth 应用处于 Testing 状态时 refresh token **7 天过期**，token 是 09-16 授权的，09-23 前后失效。

**怎么做**（一次性，约 1 分钟）：

```bash
cd ~/.workbuddy-ai/skills/SEO运营
/Users/vinco/.workbuddy-ai/binaries/python/envs/default/bin/python gsc_auth.py
# 浏览器自动打开 → 选 Google 账号 → 允许（scope 只要 webmasters.readonly）
```

授权完我就恢复 `--striking`（4–20 位打击距离词）和查询×页面矩阵能力。**没有矩阵就无法判断 `/bedtime-stories-app/` 那 73 次曝光到底来自哪些词**——这正是第 3.1 节里我唯一不敢下结论的地方。

### 4.2 Bing Webmaster Tools 验证（零成本，被严重低估）

线上实测首页 **没有任何验证 meta**：GSC / Bing / Yandex / Pinterest 全是 `NONE`。

- GSC 你是用别的方式验证的（DNS / HTML 文件），**不影响任何结论**，这里只说 Bing。
- Bing 索引喂 **ChatGPT 搜索和 Copilot**——对 MoonPage 这种「家长用自然语言问『有没有安静点的睡前故事 App』」的产品，这是比 Google 更省力的发现面。

CI 已经铺好 secret 位（`.github/workflows/deploy-pages.yml` 读 `NEXT_PUBLIC_BING_VERIFICATION`），你只需要：

1. https://www.bing.com/webmasters → 用 Google 账号登录 → **Import from Google Search Console**（一步带过）
2. 复制它给的验证码
3. 仓库 → Settings → Secrets and variables → Actions → 新建 `BING_VERIFICATION` = 那串码
4. 下次 push 自动带上 meta 标签

顺手做：Bing 后台提交 `https://moonpageapp.com/sitemap.xml`。

## 5. 度量口径（下次复盘怎么判断有没有效）

**不要看**「关键词排名」这种第三方工具数字。**只看 GSC 这三条**：

1. **非品牌查询的点击数**（当前基线：**0**）。这是唯一真正的 KPI——它从 0 变成任何正数，都说明外链开始生效。
2. **`/printable-bedtime-stories/` 的曝光与位置**（当前基线：不存在）。新页 2–4 周后开始有曝光是正常的。
3. **引用域数**（referring domains）。GSC 不直接给，用 `search.google.com/search-console/links` 或外链工具看。当前实质为 0。

**时间窗**：外链从收录到影响排名通常 4–8 周。**在 10 月中之前不要因为「排名没动」而改站内**——那会污染对照。
