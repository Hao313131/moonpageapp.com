# 标杆站 SEO 对照：学到了什么、验证了什么、落地了什么

> 日期：2026-09-28 ｜ 方法：直接抓取 6 个标杆站的 HTML / robots.txt / sitemap，逐项与本站构建产物 `out/` 对比。
> 前置：`docs/关键词排名提升_2026-09-26.md`（数据诊断）。本文是它的续篇——诊断说「站内已封盘」，本文回答「那标杆站到底强在哪」。

## 0. 一句话结论

**我们该学的不是技巧，是规模。**

抓了 6 个标杆站，逐项对比后：**本站的技术 SEO（结构化数据、robots、图片 sitemap、面包屑、GEO）已经比这些标杆站更完整**——其中两项（`Speakable`、`HowTo`）标杆站一个都没有。真正的差距只有两个：**内容规模差 10 倍**、**域名权重差一个量级**。

本轮落地一个真实动作：**新建 `/press` 外链资产页**（详见 §4）。另有一处**需要你裁决**的合规风险（§5）。

## 2. 三个真实发现

### 2.1 storyberries 封锁全部 AI 爬虫，我们全部开放 —— 这是优势，不是漏洞

storyberries 的 `robots.txt` 里有一段（`# ======Raptive Begin/End`）：

```
User-agent: ChatGPT-User      Disallow: /
User-agent: GPTBot            Disallow: /
User-agent: Google-Extended   Disallow: /
User-agent: anthropic-ai      Disallow: /
User-agent: Claude-Web        Disallow: /
User-agent: PiplBot           Disallow: /
User-agent: CCbot             Disallow: /
User-agent: FacebookBot       Disallow: /
```

**Raptive 是它的广告联盟。** 广告变现站不希望 AI 把内容抓走——用户读了 AI 摘要就不来站点了，广告展示直接受损。

**我们的选择正好相反**，而且是对的：本站靠 App 下载转化，**AI 引擎引用我们 = 免费分发**。所以 `app/robots.ts` 显式 `Allow` 了 13 个 AI 爬虫，并且有 `llms.txt` + `llms-full.txt`（64 篇指南全文）。

⚠️ **诚实标注不确定性**：AI 引荐流量在 2026 年确实在快速增长（多来源一致，但**都是营销博客的二手数据，我没有拿到一手数据**），而 `llms.txt` 的行业采用率目前**仍不确定**。保留它的理由不是「确定有效」，而是**成本为零、下行风险为零、而上行是新增分发入口**。

**结论：这是我们相对该赛道王者的结构性优势，不是待修项。** 写进这里是为了防止下次有人看到 storyberries 的 robots 就以为我们「忘了封」。

### 2.2 规模差距是 10 倍，这才是真正的差距

从 storyberries 的 sitemap 索引逐个数：

| sitemap | URL 数 |
|---|---|
| `post-sitemap1.xml` | 998 |
| `post-sitemap2.xml` | 417 |
| `page-sitemap.xml` | 81 |
| `category-sitemap.xml` | 224 |
| **合计** | **1,720** |

**我们：174 个。差 9.9 倍。**

它的 224 个分类页用了**四个正交维度**交叉覆盖长尾：

- **年龄**：`age-0-3` / `age-4-6` / `age-7-12`
- **阅读时长**：`5-min-stories` / `10-min-stories` / `15-min-stories` / `20-mins-stories-and-chapter-books`（时长维度下再分 5 个子类）
- **主题**：animal / space / monsters / dinosaurs / dragons / unicorns / mermaids / pirates / princesses / trains / dogs / cats / pigs / trucks…（约 60 个）
- **文化**：fairy-tales 按国别细分 ~20 个（French / German / Russian / Japanese / Chinese / Indian / African / Korean / Nordic / Arabic / Australian…）
- **形式**：poems / nursery-rhymes / limericks / wordless / comic-books / video-stories / colouring-books / black-and-white-baby-books
- **情绪与教育**：mindfulness / kids-meditations / growth-mindset / good-manners / feelings-and-emotions

**它靠 1,720 个页面的规模吃长尾，不是靠某个技巧。** 这也解释了为什么它不需要 `Speakable` 或 `HowTo`——规模本身就是答案。

### 2.3 但我们的架构「密度」其实更高

我一度以为我们缺主题分类，去查了自己的数据——**结论相反**：

- 我们 **22 个 collection**，每个背后有 **4–30 个故事**（`lib/stories.ts` 的 tag 计数）。
- storyberries 224 个分类 ÷ 1,415 个故事 = **平均每类 6.3 个故事**。

**我们的分类密度比它还高。** 我们不是分类不够，是**故事总量不够**（45 vs 1,415）。

同样地，我原本怀疑两个被删的 collection（`stories-about-honesty`、`stories-about-music`）是误删——**查证后否定了自己**：这两个 tag 各只有 **1 个故事**，1 个故事的 collection 页就是薄页，删掉是对的。

## 4. 本轮落地：`/press` 外链资产页

### 4.1 为什么是这一页

上一份报告 §4.3 列了 outreach 目标（Educational App Store、Raising Children Network、roundup 博主），但**缺一个能让他们引用的着陆页**。

把记者/博主引到首页，等于让他自己找事实；引到 press 页，事实、可粘贴文案、品牌素材全在眼前。**这是标准的 linkable asset 做法**，做得好的产品站都有，我们没有。

它同时承接品牌词（GSC 数据显示**我们 50 次点击 100% 来自品牌词**），并强化 `Organization` 实体。

### 4.2 页面内容（**全部可核实，零编造**）

| 板块 | 内容 |
|---|---|
| **Fast facts** | 17 行可引用事实：App 名、运营方、上架日期、平台、分类、年龄分级、价格、App Store ID、Bundle ID、语言、内容量、无广告、无追踪、无需账号 |
| **三版 boilerplate** | 25 词 / 50 词 / 100 词，编辑直接粘贴 |
| **品牌素材** | 6 个真实文件链接（图标 1024/192、社交卡 1200×630、主视觉、两张封面样例） |
| **品牌书写规范** | 4 条：MoonPage 是驼峰一个词、MoonPage ≠ EchoRealm、图标不得改色、背书需授权 |
| **Press 联系方式** | 邮箱 + App Store 列表 + 4 条站内深链 |

**每个数字都能被验证**：45 / 22 / 64 是从 `lib/stories.ts`、`lib/collections.ts`、`lib/guides.ts` 数出来的；App Store 事实来自公开列表 `id6788652725`。

> **写这一页的红线**：press 页如果夸大，比没有 press 页更糟——因为**它就是记者会引用的那一页**。所以页面上**没有**团队人数、成立时间、用户数、融资、奖项——这些我无法核实，就一个都不写。

### 4.3 接线（避免孤儿页）

- `components/Footer.tsx` → 页脚 "MoonPage" 列新增 "Press & media kit"（**全站每页都有入链**）
- `app/about/page.tsx` → "Get in touch" 列表新增 "Press and media kit"
- `app/sitemap.ts` → 新增 `/press`，`priority 0.6 / monthly`（比其它信任页高，因为它是 outreach 着陆页）
- 结构化数据：`ContactPage` + `BreadcrumbList`，挂到同一个 `Organization` 节点

## 5. ⚠️ 需要你裁决：一句没有依据的信任声明

**发现**：`SITE.trustLine` = **"Trusted by thousands of moms for calmer bedtime routines and cozy stories."**

**渲染在 4 个索引页**（含首页）：

| 页面 | 来源 |
|---|---|
| `/` | `components/home/Hero.tsx:15`（读 `SITE.trustLine`）+ `components/home/Trust.tsx:17`（硬编码） |
| `/bedtime-stories/` | 硬编码，第 136 行 |
| `/cozy-bedtime-stories/` | 硬编码，第 152 行 |
| `/bedtime-stories-app/` | 硬编码，第 123 行 |

（第 5 处 `/get/` 是 `noindex`，不计。）

**为什么这是个问题**：

1. **我核实不到依据**。App Store 公开数据显示：**AU 4 条评分、US/GB 0 条**。App 2026-07-27 上架，到现在两个月。
2. **这不是我上次修的那类 bug**。上次的 "Free on Google Play" 是**可证伪的假事实**（链接 404），100% 是缺陷。而 "thousands of moms" 是**无法证实的营销话术**——它可能是真的（如果下载量确实过千），但我拿不到数据。
3. **合规面**：澳洲 ACCC 对 misleading representations 管得比美国 FTC 更严，而这是个澳洲运营方的站。
4. **EEAT 面**：新站 + 无依据的信任声明，是 Google 评估「这个站可不可信」时的减分项。

**我为什么没有直接改**：我无法证明它是假的，且这是营销决策，不是我能单方面拍板的。**所以我出选项，你勾一个。**

| 选项 | 做法 | 代价 |
|---|---|---|
| ☐ **A. 改成可核实的具体数字** | 换成 App Store 真实评分（如 "Rated 5.0 in Australia"）或换成无数字的说法 | 需要你确认评分表述口径 |
| ☐ **B. 改成不可证伪的定性说法** | 例："Made by parents, for the last twenty minutes of the day." | 失去社会认同感，但零风险 |
| ☐ **C. 保留，但你知道依据** | 如果你有真实下载/用户数据支撑，保留原句 | 需要你确认数据存在；否则保留风险 |
| ☐ **D. 删掉这一行** | 5 处全删 | 首页 hero 少一行社会认同 |

## 6. 学习清单：还值得学、但需要你决策的

按「值不值得做」排序。**都不需要立刻决定**，列出来是为了让「学先进经验」这件事有个完整的落点。

| # | 可学的东西 | 标杆证据 | 我的判断 |
|---|---|---|---|
| 1 | **视频**（YouTube + `VideoObject` + video sitemap） | storyberries 有 `video-sitemap.xml`；sleepfoundation 有 `VideoObject` | **唯一一个我们完全没有的发现渠道。** 45 个故事做成朗读视频成本高，但「30 秒故事片段」这类短视频可复用现成插画。**要你决定投不投** |
| 2 | **作者页**（EEAT） | storyberries 有 `author-sitemap.xml`；sleepfoundation 有医学审稿署名 | 我们的 `/about` 明确写了**不编造署名作者**。如果将来有真实作者/审稿人，这是最高价值的 EEAT 补强 |
| 3 | **按阅读时长的分类**（`5-min` / `10-min` / `15-min`） | storyberries 时长维度下有 5 个子类 | ⚠️ **不建议做**：我们的故事全部约 5 分钟，做 10/15 分钟分类等于虚假承诺。`/short-bedtime-stories/` 的标题已含 "5 Minutes or Less"，已覆盖 |
| 4 | **主题分类再细分**（space / dinosaurs / unicorns…） | storyberries 约 60 个主题类 | ⚠️ **不建议做**：每个新分类需要 ≥4 个故事支撑，否则是薄页。且 GSC 里主题类查询**只有 animal 一个簇有曝光**——说明瓶颈不在分类 |
| 5 | **儿童正念 / 冥想**（`kids-meditations`、`mindfulness`） | storyberries 有这两个分类 | 🟨 2026 年成长中的方向。但 GSC 里**零曝光**，没有需求信号。观望 |
| 6 | **`SearchAction` 的 sitelinks searchbox** | 4 个标杆站全有 | ✅ 我们 168 页已有 |
