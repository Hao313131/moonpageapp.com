## 2 修好 Google Search Console 授权（5 分钟，**一次搞定，以后不用再管**）

**为什么**：授权 2026-09-23 前后过期了。**没有它我拉不到「查询×页面」矩阵，所有数据驱动的判断都停摆**——包括那个我一直没敢动的 `/bedtime-stories-app/` 标题。

> 我查过了：**网页版导出救不了这个**。GSC 的表格一次只能按**一个维度**分组（查询 / 网页 / 国家 / 设备…），导出就是导出你眼前那张表。所以「查询 × 网页」矩阵**只能走 API**，没有别的路。

### 2a 先做这个：把它变成一次性的（3 分钟，**推荐**）

现在每 7 天失效一次，是因为你的 OAuth 同意屏幕在 **Testing** 状态。Google 官方原话：

> "A Google Cloud Platform project with an OAuth consent screen configured for an **external** user type and a publishing status of **'Testing'** is issued a refresh token expiring in **7 days**."

**改成 Production 就永久解除。** 步骤：

1. 打开 https://console.cloud.google.com/auth/audience
2. 找到 **Publishing status** → 点 **PUBLISH APP** / **Publish to production**
3. 确认。会提示「需要验证」——**你不用走验证**，个人自用可以直接发布，只是授权时多一个「未验证应用」的警告页（点「高级」→「继续前往」即可）

做完这个，refresh token 就没有 7 天期限了（只剩「连续 6 个月没用」这种正常失效）。**这是根治。**
